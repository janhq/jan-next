# L12: Appearance, locales, accessibility, window sizes

## Summary

Themes and the accent colour, the eight locales (en, zh, ja, es, fr, de, ru, pt) with every visible string translated and no key showing, keyboard-only operation, focus rings, screen reader labels on icon buttons, contrast, window sizes from 900 x 600 to full screen, zoom to 150 percent, and reduced motion.

Needs: the seed and the lane's mock server for the chat surfaces. Port block 9520; start the server on 9523. No provider key is needed. Use VoiceOver (Cmd+F5) for the screen reader cases and the macOS Accessibility settings for reduce motion and increase contrast. Language is changed from the account footer menu > Language; theme and font size are in Settings > General; accent colour is in Settings > Appearance. Some pages are known to carry English text in every language (Appearance, MCP Servers, Skills, Import from Jan, the Projects page outside English and Chinese, the Office gallery outside Chinese): a case fails on each until fixed, so file one finding per page and list the locales it affects instead of one per locale.
