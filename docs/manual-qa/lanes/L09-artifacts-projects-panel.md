# L09: Artifacts, projects, workspace, right panel

## Summary

The Artifacts library, the Projects page (create, rename, delete, recovery), the workspace picker on the chat home, the right panel tabs (Browser, terminal, Files), what the agent can and cannot see of the panel, and a panel holding many tabs.

Needs: the seed, and one real provider key for the cases marked `real` (the stub model cannot present files). Port block 9490. Spare port 9494 serves a test page: in `/tmp/jan-qa/L09/site` save an `index.html` whose body reads `violet-otter-4471`, then run `python3 -m http.server 9494 --bind 127.0.0.1` there. Make two project folders, `/tmp/jan-qa/L09/proj-a` and `/tmp/jan-qa/L09/proj-b`, each holding a text file `hello.txt` that says its own name. Presented files are the ones the agent hands over with its present tool, so every Artifacts case that needs rows asks the agent for files by name.

Provider key: the recipe's `unset` loop removes every key from the shell. Export exactly one real key before launch for the `real` cases (L09-03 to L09-09 and L09-30). Before the first send in an `any` case, switch the picker to `qa-mock / mock-model`: the default model on a fresh home is `anthropic/claude-sonnet-5-5[1m]`.
