# L07: Plugins, third-party install, plugin translation

## Summary

The Plugins page in the sidebar, Settings > Built-in plugins, installing two third-party plugins from the registry (`dsh-cad` 0.17.0 and `dsh-ppt` 0.20.8) through Add plugin, switching plugins on and off with the restart-required state, install failures, and plugin translation: the offer after an install, the Translations tab (Translate, Run again, Clear, model picker, the global switch) and on-screen translation of a plugin's panel.

Needs: the seed, the network (npm registry), and the lane's mock server. Port block 9470. Start the server on 9473 with `--sequence success --repeat-last`. The successful translation cases (`real`) need one real provider key: the stub model cannot produce a translation, which L07-22 checks on purpose. Both plugins install into this lane's scratch profile only, so L08 and L13 clone a seed that does not have them. `dsh-ppt`'s own description is Chinese and `dsh-cad`'s is English, so an English UI should offer translation for the first only. L07-24 switches to Japanese (account menu > Language), where both are offered; switch back to English after it.

Provider key: the recipe's `unset` loop removes every key from the shell. Export exactly one real key before launch for L07-23 to L07-28 and none for the rest. Before the first send in a `stub` or `any` case, switch the picker to `qa-mock / mock-model`: the default model on a fresh home is `anthropic/claude-sonnet-5-5[1m]`.
