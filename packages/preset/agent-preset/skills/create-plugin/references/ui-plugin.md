# Build a Jan UI plugin

Copy `templates/decoration/` with the file-read and file-write tools. The bundle patch mounts a row named after the package; its Host `index.js` exports `apply()`, which can be empty for a UI-only plugin. The active bare-package row carries the Client half; a row naming a subpath does not. The manifest sets `jan.client.platform` to `web` and exports `./client`.

Choose an existing slot that allocates the space you need. Start with `conversation.composer.dock` for a decoration near the chat input, `statusbar.left` or `statusbar.right` when the Desktop status bar is mounted, or `shell.overlay` only for a real overlay. Settings pages use `settings.section` and can supply a matching `settings.section.icon`. A plugin's own configuration page in Customize > Plugins uses `plugins.item`; use the provided form to update live config. Check slot keys, allowed registration options, and owner props in the live `Slots` inspection catalog. In a checkout, follow the generated Client inspect catalog linked from `docs/subsystems/slots.md` and the examples in `docs/cookbook/adding-a-settings-card.md`.

## Client module

`client.js` registers a lazy factory with `window.__ModuleLoader__.load`, using the package name as its `id`. The factory returns the Client plugin's `inject` and `apply`. React and shared `@janhq/jan-client-ui-primitives` come from Jan's browser module table when available. `jan.client.inject` lists informational package edges; it neither exposes modules to `require` nor orders `apply`. Use Cordis `inject` for services and `ctx.slots.inject` to wait for the actual slot declaration. For compiled code, emit the same lazy-factory format, not browser ESM. See `packages/client/modules/README.md` for module lookup.

In `templates/decoration/client.js`, the factory registers a component in `conversation.composer.dock` using `ctx.slots.inject` and `ctx.slots.register`. Follow the selected slot's props and options from `Slots.listSubTree` when you change the slot.

Keep factories free of side effects. Own styles, timers, listeners, and other resources with `ctx.effect` or `ctx.on` inside `apply`, and return their cleanup functions. Use Jan's theme tokens for controls, containers, and motion. Register a dictionary through `ctx.locale` for visible text in all eight Jan locales (en, zh, ja, es, fr, de, ru, pt); this is separate from the package's display metadata. For examples, read `plugins/annotate/client.js` and `plugins/status-bar/client.js` in source. Do not replace the app root, mount a second app, or position a widget by inspecting another plugin's DOM. Verify that disabling the plugin removes its UI and effects.
