# Model Hub

Open Models from the Jan sidebar to browse downloadable GGUF models. Search ranks model names, developers, and quant filenames, with support for partial words and common typos. Sort defaults to the most downloaded models; search relevance comes first when there is a query. The size sort uses the smallest quant plus the catalog's vision projector, if any. The date sort uses update dates when the catalog provides them and creation dates otherwise.

Explore features Jan's own models (published by `janhq` or `Menlo`) first, then the most downloaded models that fit this computer. Each tile and the featured banner show the publisher's Hugging Face profile picture, looked up from `huggingface.co/api/{organizations,users}/<owner>/avatar` with at most four lookups at a time and one per account shared by every tile. Only pictures on `cdn-avatars.huggingface.co` are drawn; an account with Hugging Face's default picture, or none, keeps the coloured monogram, which also stays underneath until the picture decodes. The banner and the tile glow take their colours from the picture: its two strongest hues, or its average colour when the picture is nearly grey. Answers and colours persist in localStorage (`jan-model-hub.avatars.v1`): pictures for 7 days, accounts without one for 1 day; a failed lookup is retried after 60 seconds.

Each tile shows the developer, the recommended variant's size, and the catalog's download count, compacted to the locale, such as **289.5K downloads**; a model the catalog gives no count shows none.

Tools, Vision, and Installed filters combine. When llama.cpp reports the host's hardware, Fits this computer limits the list to variants estimated to fit the available memory budget. The estimate uses catalog sizes and leaves headroom for the runtime; the actual requirement depends on context length and the model. Clear filters removes the search and all selected filters without changing the sort.

Download a quant from its card, pause to retain the partial file, or confirm cancellation to discard it. The composer's model menu also offers Get local models, which closes the menu and opens the Hub for that chat. Use on an installed variant makes it the local default; opened from a chat, the Hub returns to that chat and selects the model there, otherwise it opens a new chat on it. Download from a chat's Hub returns to the chat at once, shows the download's percent beside Get local models, and, when the model is installed, makes it the default and selects it in that chat; a corner toast reports the start, the switch, or a failure. The Hub keeps that link in memory only: after a reload the download continues but the chat is not switched. The plugin uses the existing `llamaCpp` Remote and declares no new slots, configuration, or services.
