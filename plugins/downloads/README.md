# Downloads

Open Downloads from the sidebar header or More menu to manage local model downloads and Jan-managed files. The header icon shows a progress badge for the running transfer. Its tooltip and accessible label report the percentage when the total is known. Paused, failed, and waiting transfers do not show an active badge.

Pause keeps the partial file for resuming. Cancelling a transfer after confirmation discards its partial file. The sidebar header and page use the same existing `llamaCpp` state stream.
